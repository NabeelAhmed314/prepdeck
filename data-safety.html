Data types collected

Two per-type questions confuse people — answer them for this kit as:

  • Processed ephemerally? → No for everything here (the kit *stores* its data: events in PostHog, crash reports in Sentry, preps in local Room/DataStore). The job description looks like a candidate — our server forwards it without storing it — but ephemeral processing means the data never leaves, and this is shared with OpenRouter, so the honest answer is No.
  • Collected vs Shared are independent, despite Play's ONLY_COLLECTED / ONLY_SHARED response ids. The user-generated-content row is both, and ticks both boxes.
  • Required, or users choose? → Data collection is required when the user can't turn it off. Users can choose whether this data is collected only if there's a real in-app opt-out — here, Settings → Privacy → "Share usage analytics", which gates PostHog only.
